# Safe reset of the local admin password

This utility changes only the password hash for username `admin`. It does not delete or overwrite invoices, inventory, users, or other ERP data.

## Use

1. Copy this folder into the ERP project folder on the server PC. It should sit next to `data`, `node_modules`, and `work`.
2. Double-click `إعادة-تعيين-كلمة-المرور.bat` inside this folder.
3. Enter a new password twice when prompted. Use at least 14 characters and save it securely.
4. Sign in with username `admin` and the new password.

The project must have been initialized once, and its `node_modules` folder must exist. The script may start PostgreSQL temporarily if it is stopped. Do not delete `data` or `data\pgdata`.
